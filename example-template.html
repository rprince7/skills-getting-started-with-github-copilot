📋 Acerca de este componente

GreetingCard es un componente web personalizado que muestra una tarjeta de saludo animada. Utiliza Shadow DOM para encapsulación de estilos y soporta atributos personalizables.

💻 Código de Uso

Para usar este componente en tu página, simplemente incluye el script y utiliza la etiqueta personalizada:

<!-- Incluir el componente -->
<script src="greeting-card.js"></script>

<!-- Usar el componente -->
<greeting-card name="Tu Nombre" message="Tu Mensaje"></greeting-card>

Atributos disponibles:

  • name: El nombre que se mostrará en la tarjeta (por defecto: "Guest")
  • message: El mensaje de saludo (por defecto: "Hello!")

🔧 Actualización Dinámica con JavaScript

Puedes actualizar los atributos del componente dinámicamente usando JavaScript:

// Seleccionar el elemento
const card = document.querySelector('greeting-card');

// Actualizar atributos
card.setAttribute('name', 'Nuevo Nombre');
card.setAttribute('message', 'Nuevo Mensaje');
