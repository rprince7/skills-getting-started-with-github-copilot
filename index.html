🪟 Modal Window Component

Un componente web básico creado con Lit Element que implementa una ventana modal funcional.

¡Bienvenido!

Este es un ejemplo de un componente web modal básico creado con Lit Element.

Características:

  • Construido con Lit Element
  • Diseño responsive
  • Animaciones suaves
  • Cierre con tecla ESC
  • Cierre al hacer clic fuera del modal
  • Componente web reutilizable

Puedes cerrar este modal haciendo clic en el botón X, presionando la tecla ESC, o haciendo clic fuera del modal.
